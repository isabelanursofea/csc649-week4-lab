# CSC649 Week 4 Lab

A small study-planner project for practising unit tests, CI/CD and deployment.

- `src/planner.py`: the code to test
- `tests/test_planner.py`: your unit tests
- `site/index.html`: the page that is deployed
- `docs/tech-stack-evaluation.md`: your tech stack decision
- `workflows-to-copy/`: backup copies of the two workflow files (use only if pasting fails)

Run the tests:

```
pip install -r requirements.txt
pytest
```
